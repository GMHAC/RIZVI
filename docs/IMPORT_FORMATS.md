# Import Formats
1. EMPLOYEE_MASTER.csv — EMPLOYEE_ID, NAME, DESIGNATION, GRADE, DEPARTMENT, SECTION, FLOOR, LINE, CATEGORY, JOIN_DATE, MOBILE, EMAIL
2. PUNCH.csv — EMPLOYEE_ID, PUNCH_DATE, IN_HOUR, IN_MINUTE, IN_SECOND, OUT_HOUR, OUT_MINUTE, OUT_SECOND, BREAK_SECONDS, APPROVED_OT_HOURS
3. KPI_JOB_LIST.csv — DEPARTMENT, DESIGNATION, PERIOD_TYPE, TASK_CODE, TASK_TITLE, WEIGHT
4. TRAINING.csv — EMPLOYEE_ID, TRAINING_NAME, TRAINING_DATE, SOURCE_FILE
5. PRODUCTION.csv — DATE, LINE, STYLE, TARGET_QTY, ACTUAL_QTY, QUALITY_PASS_QTY, LOSS_QTY, RECOVERY_PLAN
6. SALARY.csv — Employee ID plus salary/OT columns.
All imports should be validated, logged, rejected-row reported, and mapped through Employee ID.

# RIZVI Department Dashboard Mapping

| Department | Dashboard | Primary data domains |
|---|---|---|
| Executive | Executive Command Center | Enterprise KPI, risk, people, production, cost |
| HR | HR Command Center | Employee, attendance, payroll, talent, performance, training |
| Admin | Admin Dashboard | Facilities, transport, housekeeping, services |
| Compliance | Compliance & ESG | Buyer, labour, safety, social, environmental |
| Security | Security Operations | Gate, guards, visitors, patrol, incidents, assets |
| Fire & Safety | Fire & Life Safety | Fire prevention, drills, emergency, permits |
| Quality | Quality Management | QMS, inspection, NCR, CAPA, customer quality |
| Production | Production Performance | Target, output, efficiency, line, overtime |
| IE | IE Dashboard | SMV, efficiency, capacity, manpower, line balancing |
| Maintenance | Maintenance & Engineering | PM, breakdown, utility, spare parts |
| Store | Store & Inventory | GRN, stock, issue, traceability |
| Procurement | Procurement Governance | Price, supplier, purchase, exception |
| Accounts & Finance | Finance Control | Payroll, AP, AR, cash, budget, cost |
| Internal Audit | Audit & Risk | Risk, controls, audit, exception |
| Welfare | Employee Experience | Grievance, engagement, support, retention |
| Medical | Medical Dashboard | Clinic, first aid, occupational support |
| Planning | Planning Dashboard | Order, capacity, shipment, production plan |
| PAD | PAD Dashboard | Personnel/admin/document workflows |

## Rule

Department-specific pages should be driven by configuration and APIs. A dashboard should not be duplicated just because a department has different widgets.
